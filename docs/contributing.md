# Contributing

Before opening a pull request:

1. Run focused tests for the code you changed.
2. Run `npm test` and `npm run build`.
3. Update the relevant user or developer documentation.
4. Keep credentials, private data, generated outputs, and local databases out of version control.
5. Preserve compatibility for saved experiment names and configuration formats unless a migration is included.

Update [getting-started.md](getting-started.md) when setup changes, [experiments.md](experiments.md) when user workflows change, and [architecture.md](architecture.md) or [testing.md](testing.md) when development behavior changes.
